Worum es geht

Eine Differentialgleichung (DGL) ist eine Gleichung, in der eine gesuchte Funktion \(y(x)\) zusammen mit ihren Ableitungen vorkommt. Die Lösung ist also keine Zahl, sondern eine Funktion. Beispiel: \(y' = 2y\) fragt „Welche Funktion ist abgeleitet doppelt so groß wie sie selbst?“ Antwort: \(y = C\,e^{2x}\).

Welches Verfahren? – die Entscheidung in drei Fragen

Das ist der wichtigste Schritt in jeder Aufgabe. Präge dir diese Reihenfolge ein:

ja → Trennung der Variablennein → Frage 3

Schreibweisen: \(y' = \dfrac{dy}{dx}\). Hängt die Funktion von der Zeit ab, schreibt man oft Punkte: \(\dot y = \dfrac{dy}{dt}\), \(\ddot y = \dfrac{d^2y}{dt^2}\). Das war in den alten Klausuren üblich und ändert nichts an der Rechnung.

Probe durch Einsetzen

Ob eine Funktion eine DGL löst, prüfst du immer gleich: ableiten, einsetzen, vereinfachen.

Löst \(y = C\,e^{-3x}\) die DGL \(y' + 3y = 0\)?
\[ y' = -3C\,e^{-3x} \quad\Rightarrow\quad y' + 3y = -3Ce^{-3x} + 3Ce^{-3x} = 0 \quad\checkmark \]

Das klappt für jedes \(C\). Darum heißt \(y = Ce^{-3x}\) die allgemeine Lösung.

Tipp für die Klausur

Die Probe kostet eine Minute und findet fast jeden Vorzeichenfehler. Mach sie bei jeder Lösung wenigstens im Kopf.

2 · Klassifizieren 2.1 Prüfer

Gefragt sind Ordnung, linear oder nichtlinear und bei linearen DGL homogen oder inhomogen.

So gehst du vor

  1. Ordnung: höchste Ableitung suchen.
  2. Linear? Die gesuchte Funktion \(y\) und alle Ableitungen kommen nur „pur“ und in erster Potenz vor: kein \(y^2\), kein \(y\cdot y'\), kein \(\sqrt y\), \(e^y\), \(\sin y\), \(\frac1y\). Die Faktoren davor dürfen von \(x\) abhängen (\(x\,y'\), \(e^x y\) sind erlaubt).
  3. Homogen? (nur bei linear) Alle Terme mit \(y\) auf die linke Seite. Bleibt rechts \(0\), ist sie homogen. Steht rechts etwas, das nur von \(x\) abhängt (die Störfunktion), ist sie inhomogen.
  4. Optional: konstante Koeffizienten? Trennbar?

Beispiel aus dem Anforderungsdokument

DGLOrdnunglinear?homogen?Begründung
a) \(y' + 3y = 0\)1linearhomogen\(y, y'\) nur einfach, rechts 0
b) \(y'' + 4y' + 5y = 8\)2linearinhomogenStörfunktion \(s = 8\), konstante Koeffizienten
c) \(y' = x\,y^2\)1nichtlinear–\(y^2\). Aber trennbar!
d) \(y''' + 2y' = 0\)3linearhomogenhöchste Ableitung \(y'''\), rechts 0

Typische Fehler

  • \(x^2 y'\) für nichtlinear halten. Nichtlinear wird es nur durch die gesuchte Funktion, nicht durch \(x\).
  • Bei „homogen“ nicht umsortiert: \(y' = 3y\) ist homogen (\(y' - 3y = 0\)), \(y' = 3y + x\) ist inhomogen.
  • Bei nichtlinearen DGL nach homogen/inhomogen gefragt: Die Einteilung gibt es nur bei linearen.

3 · Integrations-Werkzeugkasten

Beim Lösen von DGL erster Ordnung wird am Ende fast immer integriert. Die meisten Fehler passieren dabei, nicht bei der DGL selbst. Das hier ist der Ausschnitt aus deiner Mathe-1-Formelsammlung, der wirklich gebraucht wird.

\(\tan x = \frac{\sin x}{\cos x}\)\(-\ln|\cos x|\)\(\frac{1}{\tan x} = \frac{\cos x}{\sin x}\)\(\ln|\sin x|\)
\(\frac{1}{\sqrt x} = x^{-1/2}\)\(2\sqrt x\)\(\frac{1}{ax+b}\)\(\frac1a\ln|ax+b|\)

Die drei Tricks, die immer wieder vorkommen

A · Logarithmische Integration

Steht im Zähler die Ableitung des Nenners:

\[ \int\frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C \]

Beispiele: \(\int\frac{2x}{1+x^2}dx = \ln(1+x^2)\), \(\ \int\frac{x}{1+x^2}dx = \frac12\ln(1+x^2)\), \(\ \int\frac{1}{y-2}dy = \ln|y-2|\).

B · Substitution

  1. Inneren Ausdruck \(u = g(x)\) wählen, z. B. \(u = 1 + x^2\).
  2. \(\frac{du}{dx} = g'(x)\), also \(dx = \frac{du}{g'(x)}\).
  3. Einsetzen, alle \(x\) müssen verschwinden.
  4. Integrieren, dann \(u\) zurückersetzen.
Substitution aus dem Anforderungsdokument: \(\displaystyle\int\frac{x}{1+x^2}\,dx\) mit \(u = 1 + x^2\)
\[ u = 1 + x^2,\quad \frac{du}{dx} = 2x \Rightarrow dx = \frac{du}{2x} \qquad\int\frac{x}{u}\cdot\frac{du}{2x} = \frac12\int\frac{du}{u} = \frac12\ln|u| = \frac12\ln(1 + x^2) + C \]

C · Partialbruchzerlegung (seltener)

Für Brüche wie \(\frac{1}{y(1-y^2)}\): Nenner in Faktoren zerlegen, Ansatz \(\frac{A}{y} + \frac{B}{1-y} + \frac{C}{1+y}\), Nullstellen des Nenners einsetzen, dann jeden Teil mit \(\ln\) integrieren. Kam in der Klausur vom 21.06.2024 vor.

Nach dem Integrieren: nach \(y\) auflösen

RegelAnwendung
\(\ln|y| = A \iff |y| = e^{A}\)beide Seiten „hoch e“
\(e^{u + C} = e^u\cdot e^C\)Konstante abtrennen
\(\pm e^C =: K\)neue Konstante, der Betrag verschwindet darin
\(\ln a + \ln b = \ln(ab),\quad k\ln a = \ln a^k\)Logarithmen zusammenfassen

4 · Trennung der Variablen 2.2 Prüfer

Wann? Immer wenn sich die rechte Seite als Produkt aus einem reinen \(x\)-Teil und einem reinen \(y\)-Teil schreiben lässt:

\[ y' = f(x)\cdot g(y) \]
DGLtrennbar?\(f(x)\cdot g(y)\)
\(y' = 2xy\)ja\(2x\cdot y\)
\(y' = 3e^{x+y}\)ja\(3e^x\cdot e^y\)  (Potenzgesetz!)
\(y' = 6 - 2y\)ja\(1\cdot(6 - 2y)\)
\(\tan x\cdot y' = 1 + y\)ja\(\frac{1}{\tan x}\cdot(1+y)\)
\(y' = x + y\)neinSumme lässt sich nicht zerlegen → linear lösen

Rezept

  1. \(y'\) als \(\frac{dy}{dx}\) schreiben.
  2. Trennen: alles mit \(y\) samt \(dy\) nach links, alles mit \(x\) samt \(dx\) nach rechts: \(\dfrac{dy}{g(y)} = f(x)\,dx\).
  3. Integrieren: beide Seiten. Nur eine Konstante \(C\), auf der rechten Seite.
  4. Nach \(y\) auflösen (Tabelle oben).
  5. Konstante Lösungen prüfen: Wo \(g(y) = 0\) ist, hast du beim Teilen eine Lösung verloren. Meist ist sie mit \(K = 0\) wieder enthalten.
  6. Anfangsbedingung einsetzen und \(C\) bestimmen. Erst ganz am Ende.
  7. Probe.

Beispiel 1 aus dem Anforderungsdokument

\(y' = 2xy\),  \(y(0) = 2\)
a
Trennen: \(\dfrac{dy}{dx} = 2x\,y \;\Rightarrow\; \dfrac{1}{y}\,dy = 2x\,dx\)  (für \(y \ne 0\))
b
Integrieren: \(\displaystyle\int\frac1y\,dy = \int 2x\,dx \;\Rightarrow\; \ln|y| = x^2 + C\)
c
Allgemeine Lösung: \(|y| = e^{x^2 + C} = e^C\cdot e^{x^2}\). Mit \(K = \pm e^C\): \[ y = K\,e^{x^2},\quad K\in\mathbb R \] \(K = 0\) liefert \(y = 0\), die beim Teilen verlorene Lösung.
d
Spezielle Lösung: \(y(0) = K\,e^0 = K = 2\), also \(y = 2\,e^{x^2}\)

Probe: \(y' = 2\cdot 2x\,e^{x^2} = 2x\cdot y\) ✓

Beispiel 2 aus dem Anforderungsdokument

\(y' = \dfrac{x(1 + y^2)}{1 + x^2}\)
1
Trennen: \(\dfrac{dy}{1 + y^2} = \dfrac{x}{1 + x^2}\,dx\). Hier ist \(1 + y^2\) nie null, es geht also keine Lösung verloren.
2
Linke Seite: Grundintegral \(\displaystyle\int\frac{dy}{1 + y^2} = \arctan y\)
3
Rechte Seite mit \(u = 1 + x^2\), \(du = 2x\,dx\): \(\displaystyle\int\frac{x}{1+x^2}dx = \frac12\int\frac{du}{u} = \frac12\ln(1 + x^2)\)
4
\(\arctan y = \tfrac12\ln(1 + x^2) + C\). Auf beide Seiten \(\tan\) anwenden: \[ y = \tan\!\left(\tfrac12\ln(1 + x^2) + C\right) \]

Kein Betrag im \(\ln\) nötig, weil \(1 + x^2 > 0\).

5 · Lineare DGL 1. Ordnung 2.3 Prüfer

Eine lineare DGL erster Ordnung lässt sich immer in die Normalform bringen:

\[ y' + a\,y = s(x) \qquad a: \text{Koeffizient},\quad s(x): \text{Störfunktion} \]

Die Lösung setzt sich aus zwei Teilen zusammen. Das ist das Prinzip, das du auch in Teil 2 wieder brauchst:

\[ y = \underbrace{y_h}_{\text{löst } y' + ay = 0} + \underbrace{y_p}_{\text{irgendeine Lösung von } y' + ay = s(x)} \]

Rezept

  1. Normalform herstellen: Faktor vor \(y'\) wegdividieren.
  2. Homogene DGL \(y' + ay = 0\) aufschreiben und lösen: \(y_h = C\,e^{-ax}\).
  3. Ansatz für \(y_p\) nach der Tabelle unten wählen (Typ der rechten Seite).
  4. Ansatz ableiten, einsetzen, Koeffizienten vergleichen und \(A, B, \dots\) bestimmen.
  5. Allgemeine Lösung: \(y = y_h + y_p\).
  6. Anfangsbedingung erst jetzt einsetzen, nicht schon in \(y_h\).

Warum \(y_h = C\,e^{-ax}\)?

Die homogene DGL ist trennbar: \(\frac{dy}{y} = -a\,dx \Rightarrow \ln|y| = -ax + c \Rightarrow y = C\,e^{-ax}\). Das musst du nicht jedes Mal herleiten, aber einmal verstanden haben.

Typische Fehler

  • Polynom-Ansatz unvollständig: Für \(4x\) reicht \(Ax\) nicht, es muss \(Ax + B\) sein.
  • Bei \(\sin\) nur \(A\sin\) angesetzt. Ableiten macht aus \(\sin\) einen \(\cos\), deshalb braucht man beide.
  • Anfangsbedingung schon in \(y_h\) eingesetzt statt in die Gesamtlösung \(y_h + y_p\).
  • Störfunktion ist die Lösung der homogenen DGL (\(b = -a\)): Dann liefert der normale Ansatz \(0 = s\). Lösung: mit \(x\) multiplizieren.

\(2Ax + B - 3Ax^2 - 3Bx - 3D = 9x^2\). Vergleich: \(x^2\): \(-3A = 9 \Rightarrow A = -3\). \(x\): \(2A - 3B = 0 \Rightarrow B = -2\). konstant: \(B - 3D = 0 \Rightarrow D = -\tfrac23\).

\(y = Ce^{3x} - 3x^2 - 2x - \tfrac23\)

Übung · harmonisch\(y' + y = 2\sin x\)Lösung

\(y_h = Ce^{-x}\). Ansatz \(y_p = A\sin x + B\cos x\), \(y_p' = A\cos x - B\sin x\).

Einsetzen und sortieren: \((A - B)\sin x + (A + B)\cos x = 2\sin x\). Also \(A - B = 2\) und \(A + B = 0\), d. h. \(A = 1,\ B = -1\).

\(y = Ce^{-x} + \sin x - \cos x\)

Übung · Sonderfall\(y' + 2y = e^{-2x}\)Lösung

\(y_h = Ce^{-2x}\). Die Störfunktion hat dieselbe Form wie \(y_h\). Der Ansatz \(Ae^{-2x}\) ergibt \(0 = e^{-2x}\) und scheitert.

Deshalb \(y_p = A\,x\,e^{-2x}\), \(y_p' = Ae^{-2x} - 2Axe^{-2x}\). Einsetzen: \(Ae^{-2x} = e^{-2x} \Rightarrow A = 1\).

\(y = (x + C)\,e^{-2x}\)

21.06.2024 · a ii\(2y' + x\,y = 6x\)Lösung

Normalform: \(y' + \tfrac{x}{2}y = 3x\). Der Koeffizient hängt von \(x\) ab, aber die DGL ist auch trennbar: \(y' = \tfrac{x}{2}(6 - y)\).

\(\dfrac{dy}{6 - y} = \tfrac{x}{2}dx \Rightarrow -\ln|6 - y| = \tfrac{x^2}{4} + c \Rightarrow 6 - y = Ke^{-x^2/4}\)

\(y = 6 + C\,e^{-x^2/4}\). Kurzer Weg: \(y_p = 6\) sieht man durch Hinschauen (\(0 + \tfrac x2\cdot 6 = 3x\) ✓).

Anwendung aus der E-Technik: Kondensator laden

Reihenschaltung aus \(R\) und \(C\) an Gleichspannung \(U_0\): \(RC\,\dot u + u = U_0\), \(u(0) = 0\).

Normalform \(\dot u + \frac{1}{\tau}u = \frac{U_0}{\tau}\) mit \(\tau = RC\). Dann \(u_h = Ke^{-t/\tau}\), \(u_p = U_0\) (Konstante), \(u(0) = K + U_0 = 0\).

\(u(t) = U_0\left(1 - e^{-t/\tau}\right)\)

Genau das Schema von Beispiel 1, nur mit anderen Buchstaben.

6 · Variation der Konstanten Zusatz aus dem alten Stoff

Der neue Prüfer nennt nur den Ansatz vom Typ der rechten Seite. In den alten Klausuren kamen aber oft lineare DGL wie \(x\,y' - y = x^2\) vor, deren Koeffizient von \(x\) abhängt. Dann klappt der Tabellen-Ansatz nicht zuverlässig, und dieses Verfahren hilft. Es funktioniert bei jeder linearen DGL 1. Ordnung.

Rezept

  1. Normalform \(y' + a(x)\,y = s(x)\).
  2. Homogene DGL durch Trennung lösen: \(y_h = C\cdot h(x)\) mit \(h(x) = e^{-\int a(x)dx}\).
  3. Konstante „variieren“: \(y = C(x)\cdot h(x)\) ansetzen und einsetzen. Die Terme ohne \(C'\) heben sich immer weg (gute Kontrolle!). Übrig bleibt \(C'(x)\cdot h(x) = s(x)\).
  4. \(C(x) = \int\frac{s(x)}{h(x)}dx + K\).
  5. \(y = C(x)\cdot h(x)\).
04.04.2025 · a ii: \(x\,y' - y = x^2\)
1
Normalform: \(y' - \frac1x y = x\)
2
Homogen: \(\frac{dy}{y} = \frac{dx}{x} \Rightarrow \ln|y| = \ln|x| + c \Rightarrow y_h = C\,x\)
3
\(y = C(x)\,x\), \(\ y' = C'x + C\). Einsetzen: \(C'x + C - \frac1x\,C\,x = C'x = x\)
4
\(C' = 1 \Rightarrow C(x) = x + K\)

\(y = (x + K)\,x = x^2 + Kx\)

11.12.2024 · a ii\(x\,y' + y = x + 2\)Lösung

Normalform \(y' + \frac1x y = 1 + \frac2x\). Homogen: \(y_h = \frac{C}{x}\).

\(y = \frac{C(x)}{x}\) einsetzen: \(\frac{C'}{x} = 1 + \frac2x \Rightarrow C' = x + 2 \Rightarrow C = \frac{x^2}{2} + 2x + K\).

\(y = \frac{x}{2} + 2 + \frac{K}{x}\)

Abkürzung: Die linke Seite ist \((x\,y)'\) (Produktregel), also gleich integrieren.

28.03.2024 · a ii\(x\,y' - y = x + 2\)Lösung

Normalform \(y' - \frac1x y = 1 + \frac2x\). Homogen: \(y_h = Cx\).

\(C'x = 1 + \frac2x \Rightarrow C' = \frac1x + \frac{2}{x^2} \Rightarrow C = \ln|x| - \frac2x + K\).

\(y = x\ln|x| - 2 + Kx\)

7 · Mischtraining: Verfahren erkennen

Erst entscheiden, dann aufklappen. Das Erkennen ist in der Klausur der halbe Weg.

\(y' = x\,y^2\)Verfahren

Nichtlinear, aber trennbar: \(f(x) = x,\ g(y) = y^2\). → Abschnitt 4

\(y' = x + y\)Verfahren

Nicht trennbar (Summe), aber linear: \(y' - y = x\). \(y_h = Ce^x\), Ansatz \(y_p = Ax + B\) ergibt \(A = -1,\ B = -1\). \(y = Ce^x - x - 1\)

\(y' + 4y = 8\)Verfahren

Linear mit konstantem Koeffizienten und konstanter Störfunktion. Geht auch per Trennung. \(y = Ce^{-4x} + 2\)

\(x\,y' - y = x^2\)Verfahren

Linear, Koeffizient hängt von \(x\) ab → Variation der Konstanten.

\(y' = 3\,e^{x + y}\)Verfahren

Nichtlinear, trennbar nach Zerlegen \(e^{x+y} = e^x e^y\).

\(x^2y' + y^2 = x\,y\)Verfahren

Nichtlinear (\(y^2\)) und nicht trennbar. Das ist eine Bernoulli-DGL, sie steht nicht im neuen Anforderungsdokument.

\(y'' - 5y' + 6y = 0\)Verfahren

2. Ordnung, linear, homogen, konstante Koeffizienten → charakteristische Gleichung, Teil 2.

Baustein für deine zwei A4-Seiten

Zusammen mit dem Komplex-Baustein ist damit etwa eine Seite gefüllt. Die zweite Seite bleibt für Teil 2.

Klassifizieren

Ordnung = höchste Ableitung · linear: \(y, y', \dots\) nur in 1. Potenz, nicht in Funktionen, nicht multipliziert · homogen: Störfunktion \(s(x) = 0\)

Trennung der Variablen

\(y' = f(x)\,g(y) \Rightarrow \int\frac{dy}{g(y)} = \int f(x)\,dx + C\) · \(\ln|y| = u + C \Rightarrow y = Ke^{u}\) · \(g(y) = 0\) prüfen

Linear 1. Ordnung

\(y' + ay = s\) · \(y_h = Ce^{-ax}\) · Ansatz: \(c \to A\), Polynom → Polynom gleichen Grades, \(e^{bx} \to Ae^{bx}\) (bei \(b = -a\): \(Axe^{bx}\)), \(\sin/\cos \to A\sin + B\cos\) · \(y = y_h + y_p\), AWP zuletzt

Variation der Konstanten

\(y_h = C\,h(x)\), \(y = C(x)\,h(x)\) einsetzen ⇒ \(C' h = s\) ⇒ \(C = \int\frac{s}{h}dx + K\)

Integrale

\(\int\frac{f'}{f} = \ln|f|\) · \(\int\frac{1}{1+x^2} = \arctan x\) · \(\int\tan x = -\ln|\cos x|\) · \(\int e^{ax} = \frac1ae^{ax}\) · \(\int x^{-1/2} = 2\sqrt x\) · Substitution: \(u = g(x),\ dx = \frac{du}{g'(x)}\)
